# exploded-view-for-dog-robot

# how to create exploded view 
1-Open the Exploded views panel in the Assembly.

2-Create one Exploded View.

3-Inside that same view, add multiple Explode steps for all the parts.

4-Activate that Exploded View the movements from every step inside it will appear together.
